# Example artifacts

`cpu_fixture/` contains actual output from this package's CPU-only software fixtures.
They are **not robot simulation**, contain no learned-model inference, and make no claims
about task completion, visual reasoning, memory benefit, or recovery competence.

Open each `report.html` to see the evidence format. Do not use this material as an investor
robot demonstration. On a GPU run, the same report format will display actual simulator
camera observations and native evaluator results with their provenance/limitations.
