# Earlier EmbodiedSWE solution transfer

## Why this baseline

The current nonprivileged integration has not systematically carried over the
earlier successful contact execution. A matched free-space IK test does not
replace a contact-capable reference. Replay the unchanged frozen solution first,
then replace privileged inputs explicitly. This is a diagnostic prerequisite,
not a redefinition of the adaptive-execution objective as scripted success.

## Earlier evidence

The sibling `embodied-technical-work` project retained the solution under
`artifacts/server_repair_demo_20260927/frozen_solution`.
Public source: [frozen solution](https://github.com/AranKomat/codex-embodied-technical-work/tree/bca3a0868dcddcc816307085c86004304c77b778/artifacts/server_repair_demo_20260927/frozen_solution).
Its progress handoff reports 6/6 same-fixture trials and 3/3 trials with seed-2
card XY jitter of +/-10 mm. Those are historical results, not new replications.
The successful final solution uses OSC, despite an earlier DiffIK comparison
showing better orientation stability. Relative feedback and controller choice
are different dimensions; neither result establishes a universal winner.

camera transforms and measured depth are different: they can be available on a
real system, although our depth is currently idealized simulator depth.

## Bounded replay

`scripts/replay_privileged_reference.py` loads external frozen source unchanged,
hashes its Python files, runs seed 0 with a 5,000-action cap, and records stage
checks, card trajectories and final scene predicates. It makes no paid calls.
Only checks/step logging are wrapped; solver actions are not modified.
Diagnostic health is derived from the same scene success predicate, not an
independent electronic measurement. No video is captured by this runner.

The existing step-280 nonprivileged episode stays paused in a separate process.
Do not reuse privileged reference trajectories as observations in that episode.

Run from this repository in the existing Isaac Python environment:

```bash
OMNI_KIT_ACCEPT_EULA=YES CUDA_VISIBLE_DEVICES=0 \
  upstream/EmbodiedSWE/.venv/bin/python scripts/replay_privileged_reference.py \
  --repo upstream/EmbodiedSWE --solution /path/to/frozen_solution \
  --output runs/privileged_reference_replay_20260929 --headless
```

The output directory must not already exist; there is no automatic retry.

## New replay result

The seed-0 current-substrate replay **passed all three stages**:

| Stage | Cumulative actions | Check |
|---|---:|---|
| Grasp and stable lift | 620 | pass |
| Carry and interior alignment | 1,291 | pass |
| Seat, release and hand clearance | 1,859 | pass |

Final scene success and seated predicates were true, grasp-held was false, and
the unchanged final stage required hand/card vertical clearance greater than
0.28 m. Wall time from before environment construction was 570.834 s. No GPT or
FLUX calls occurred. Only one fresh seed was tested; this is not a new robustness
claim. The source uses privileged state and the benchmark's grasp assistance.
It does not prove autonomous target selection, sensor-only grasping, unassisted
contact physics, or adaptive recovery.

Full logs, sampled card trajectory and source hashes are backed up locally in
`runs/privileged_reference_replay_20260929`. Compact machine-readable evidence is
under `docs/evidence/privileged_reference_replay_20260929`. No rendered video was
captured. Existing simulator and FLUX service processes remained alive, and the
separate replay process exited normally. The nonprivileged episode was untouched.

This establishes that the old contact-capable execution structure transfers to
the current substrate. It does not identify how much each individual old fix
contributed; that would require ablations. The next experiment should substitute
sensor-derived grasp geometry while preserving the qualified motor route, not
repeat controller/model searches. The full adaptive objective remains open.
